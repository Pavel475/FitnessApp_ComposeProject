# Документ «Модель угроз безопасности» приложения FitnessApp (v1.0)

---

## 1. Описание системы

**FitnessApp** — мобильное Android-приложение для составления персональных программ тренировок, отслеживания спортивного прогресса и учета калорий/физических показателей пользователя.

### Архитектура и технологии:
* **UI-слой:** Jetpack Compose, Material 3, Single-Activity Architecture, StateFlow.
* **Сетевой слой:** Retrofit 2, OkHttp 4, Gson / KotlinX Serialization.
* **Взаимодействие с сервером:** REST API на базе сервиса MockAPI.io (`https://6aeb53b0ee39618d7bf83243.mockapi.io/workouts/`).
* **Локальное хранилище:** Внутреннее приватное хранилище приложения (`context.filesDir`), использование `fitness_profile_report.json` для локального кэша и состояния отчетов.
* **Импорт/Экспорт отчетов:** Storage Access Framework (SAF) через системные интенты `ACTION_CREATE_DOCUMENT` и `ACTION_OPEN_DOCUMENT`.

### Пользователи и роли:
* **Обычный атлет (User):** Единоличный владелец устройства, осуществляющий локальную настройку профиля (рост, вес, калории, выполненные тренировки) и управление списком упражнений.

## 3. Границы доверия (Trust Boundaries)

1. **TB1: Граница «Приложение <-> Внешний REST API (MockAPI.io)»**  
   Пересечение данных через нестабильную/недоверенную сеть (Public Internet / Wi-Fi). Необходима проверка сертификатов и валидация входящего JSON.
2. **TB2: Граница «Приложение <-> Операционная система Android (SAF / Storage)»**  
   Передача JSON-отчета через `ContentResolver` / `Uri`. Файл вне контроля приложения может быть модифицирован сторонними приложениями до момента импорта.
3. **TB3: Граница «Процесс приложения <-> Память устройства / Изолированное хранилище `filesDir`»**  
   Приватная зона приложения. Защищена правами доступа ОС Android, но уязвима на устройствах с Root-доступом или при наличие вредоносного ПО со сбором данных из RAM.

## 5. Поверхность атаки (Attack Surface / Entry Points)

1. **EP1: SAF Input Stream (`ActivityResultContracts.OpenDocument`)** — чтение невалидного JSON отчета со стороннего накопителя.
2. **EP2: Network REST API Responses (`MockAPI.io`)** — обработка входящих HTTP-ответов от сетевого слоя Retrofit.
3. **EP3: UI Input Fields (Текстовые поля и кастомные параметры упражнений)** — потенциал Injection-атак и переполнений.
4. **EP4: Внутренний файл кэша (`fitness_profile_report.json`)** — чтение/запись данных из `filesDir`.
5. **EP5: Интенты и переходы навигации Jetpack Compose Navigation** — подмена параметров при передаче аргументов между экранами.
6. **EP6: Буфер обмена ОС Android (System Clipboard)** — кража экспортируемых текстовых сведений при копировании.

## 7. Дерево атаки (Attack Tree) для критичной угрозы U1

**Цель атакующего:** Скомпрометировать приложение или вызвать отказ в обслуживании (Crash/DoS) путем импорта стороннего JSON-файла отчета через SAF.

```text
Цель: Вызвать сбой или внедрить вредоносные данные через импорт отчета SAF (U1)
 ├── 1. Подать на вход приложение битый / невалидный JSON [ЗАКРЫТО]
 │    ├── 1.1. Передать пустой файл или случайные бинарные байты
 │    │    └── Контрмера: Валидация схемы через kotlinx.serialization и try-catch в Dispatchers.IO
 │    └── 1.2. Передать структурированный JSON с неподдерживаемой версией schemaVersion (v999)
 │         └── Контрмера: Проверка версии формата schemaVersion <= CURRENT_VERSION
 ├── 2. Вызвать исчерпание ресурсов (Out-of-Memory DoS) [ЗАКРЫТО]
 │    ├── 2.1. Передать JSON-файл размером > 50 МБ через SAF
 │    │    └── Контрмера: Проверка размера InputStream перед чтением (ограничение до 5 МБ)
 │    └── 2.2. Создать глубоко вложенный JSON-массив
 │         └── Контрмера: Ограничение глубины парсинга JsonConfig
 └── 3. Выполнить подмену бизнес-показателей (Vulnerability in Validation) [ЧАСТИЧНО ЗАКРЫТО]
      ├── 3.1. Указать отрицательный вес (-70 кг) или выходящее за границы количество калорий
      │    └── Контрмера: Валидация диапазонов значений (coerceIn / require)
      └── 3.2. Внедрить спецсимволы в имя атлета для вызова визуальных багов в Compose
           └── Защита: Санитизация строк при отображении в UI
```
